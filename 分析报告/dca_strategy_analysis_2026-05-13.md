## 3. 核心风险推演

### 🔴 风险一：在最贵的时候加速买入

```
当前 ERP = -0.35%（性价比为负）

你每投入 1 元买纳指，预期回报 < 国债无风险收益
300/日 = 每月白送 6,600 元的"负溢价税"
500/日 = 每月白送 11,000 元的"负溢价税"

提高定投 = 在最差的价格上加速消耗弹药
```

### 🔴 风险二：弹药耗尽 vs 黄金坑

这是最致命的问题。假设 6-12 个月内出现一次 -20% 级别回调（类似 2022 年），NDX 从 29,300 回踩至 ~23,400（200 日线下方），此时：

| 方案 | 到那时的剩余子弹 | 能否全力出击 |
| :--- | ---: | :--- |
| **300/日** (净增长) | ~78,000 - 86,000 元 | ✅ 子弹充裕，可连续 5-6 天顶格 14,000 打入 |
| **500/日** (净消耗) | ~52,000 - 61,000 元 | ⚠️ 弹药缩水，且已在高位消耗大量成本 |

**核心矛盾**：在红灯区加速定投 = 用高价筹码稀释了未来抄底的能力。

### 🟡 风险三：心理压力

500/日意味着月现金流变为负数（-3,000/月）。如果市场连续 3-6 个月横盘或下跌，你面对的是：
- 持仓浮亏
- 现金每月减少
- 双重心理压力

## 4. 分层策略建议

### 严格按 SKILL.md 纪律：🔴 红灯 → 中止定投

SKILL.md 明确规定：红灯状态下**"中止任何每日定投/脉冲买入动作"**。严格执行意味着：

> 300/日也应暂停，70,000 元 + 每月 8,000 元全部锁入固收理财。

### 如果你心理上无法接受完全停手（务实方案）

我理解定投的核心价值在于"克服择时焦虑"和"纪律性"。如果你选择不完全中止：

| 灯号 | 建议定投金额 | 逻辑 |
| :---: | ---: | :--- |
| 🔴 红灯 (当前) | **100 元/日** (降档) | 维持纪律感，但大幅降低高位成本。月支出仅 2,200，现金流盈余 5,800 |
| 🟡 黄灯 | **300 元/日** (恢复) | 估值回到合理区间，正常定投节奏 |
| 🟢 绿灯 | **500 元/日** (提档) | ERP ≥ 2.0%，击球区到来，此时才值得加速部署 |

### 这套分层方案的效果

```
红灯期 (假设持续 6 个月)：
  投入 = 100 × 22天 × 6月 = 13,200 元（低成本试探）
  子弹增长 = (8,000 - 2,200) × 6 = +34,800 元
  到绿灯时子弹 = 70,000 + 34,800 = 104,800 元 🎯

绿灯到来时：
  500/日 × 22天 = 11,000/月
  104,800 元子弹 + 8,000/月现金流
  可持续高强度定投 ~13 个月，在最佳价格上集中火力
```

## 5. 最终裁决

> [!CAUTION]
> **不要在红灯区提高定投金额。**
>
> 500/日方案在当前市况下是"在最贵的餐厅点最多的菜"。
>
> 正确策略：**红灯降档 → 黄灯恢复 → 绿灯加码**。把子弹留给 ERP ≥ 2.0% 的黄金坑。

| 决策项 | 建议 |
| :--- | :--- |
| 定投金额 | 🔴 红灯期降至 **100/日**（或严格中止） |
| 何时恢复 300/日 | 🟡 黄灯（ERP 回到 0%-2%，US10Y < 4.35%） |
| 何时提至 500/日 | 🟢 绿灯（ERP ≥ 2.0%，PCR > 0.8） |
| 70,000 子弹 | 锁入固收理财，等待击球区全力输出 |

> [!TIP]
> **巴菲特名言：投资的第一条规则是不要亏钱，第二条规则是记住第一条。**
> 在 ERP 为负的市场里，耐心持有现金本身就是一种"收益" — 你在赚取无风险利率的同时，保留了未来抄底的全部火力。
