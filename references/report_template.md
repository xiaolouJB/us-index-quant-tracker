# 巡检报告标准 SLA 模板（强制严格执行）

针对每一次巡检触发，**必须百分之百**严格复制并填充以下 Markdown 骨架。规则：

0. **报告必须以【📚 小白必读】板块打头**（紧随今日操作速览之后、进阶数据区之前），严格按 `references/beginner_layer.md` 的五维体检框架、指标三件套、天气预报口径、冲突仲裁规则撰写。这是面向普通读者的主体，不得省略、不得敷衍。
1. **共用层只输出一次**（进阶数据区第一部分），双核共享，禁止在 NDX/SPX 专属层内重复。
2. **NDX 与 SPX 专属层结构必须完全一致**，各自完整输出【0】–【6】，禁止以"同上""仅展示差异"等方式精简任何一方。
3. 关键数据必须完整展示（不得省略字段、不得写成一段话）。纯数字的窄表用 Markdown 表格；含长文本句子的内容一律用结构化列表呈现（手机端优先，禁止出现需要横向滚动的宽表）。中文排版规范（三合一）：中英文/数字之间加半角空格（盘古之白鹭）、中文语境用全角标点、直引号转弯引号（由 build_report.py 的 pangu() 自动处理，写 narrative 时不用手动加）；数字区数值加粗（Robinhood 式小标签+大数字），解读区标签加粗、长句不加粗（Apple 式克制）。
4. 禁止省略【今日操作速览】、【小白必读】、【核心变量环比表】与末尾免责声明。
5. **收盘价行必须在"当前数值"列内嵌当日涨跌幅**，格式：`价格 (±x.xx%)`，禁止只给价格。
6. **隐私红线：报告中严禁出现任何具体资金金额**（资金池规模、单日带宽、定投元数等均为个人数据）。操作指令一律使用以下标准话术档位：
   - 申购/机动加仓：**火力全开 / 分批建仓 / 小额脉冲 / 观望 / 全面暂停**
   - 定投：**加倍 / 正常执行 / 减半 / 暂停**
   - 网格：**激活 / 待命 / 冻结**
