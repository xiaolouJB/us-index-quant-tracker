# 季度宏观锚定模块 L / M / N（Quarterly Deep-Dive）

> ⚠️ **仅在每季度首次巡检时运行一次**，为季度级宏观背景定位服务，不进入日常周度巡检的辅助参考层，不占常规报告版面，不直接触发单次操作变更。
>
> 编号说明：2026-06 重构时由旧编号 L/O/P 规范化为 L/M/N（内容不变）。历史报告中的"模块O（新高新低比）"对应现模块 M，"模块P（全球流动性）"对应现模块 N。

## 模块 L：融资杠杆水位（季度 · 系统脆弱性快照）
1. **数据**：FINRA 每月 Margin Debt；计算同比增速（YoY%）及对全市场总市值占比。
2. **分区**：低杠杆（< 0% YoY）/ 中性（0–20%）/ **高杠杆预警（> 20% 或占比创80%分位新高）** / **极端（> 40% 或历史新高）**。
3. **季度联动**：判定为"高杠杆预警"及以上 → 当季所有巡检的机动资金额度**额外叠加九折收紧**，直至下季度更新。
4. **来源**：`finra.org` Margin Statistics / yardeni.com 历史分位图。

## 模块 M：新高新低比（季度 · 市场内部健康度校准）
1. **数据**：NYSE/NASDAQ 52周新高/新低数量；NH-NL Ratio = 新高/(新高+新低)，取近1个月均值。
2. **分区**：强势健康（> 70%）/ 中性（40–70%）/ **内部预警（< 40% 且指数在高位）** / **内部溃败（< 20%）**。
3. **季度联动**：内部预警 → 当季所有🟡黄灯巡检自动升级为偏红处理；内部溃败 + 结构破坏（模块E）→ 当季定投减半。
4. **来源**：Barchart.com / StockCharts.com `$USHL`。

## 模块 N：全球流动性水位（季度 · M2增速宏观背景）
1. **数据**：美国 M2 同比增速（FRED `M2SL`，`scripts/fetch_fred.py` 已输出）；四大央行（Fed+ECB+BoJ+PBoC）资产负债表3个月净变化方向（人工核实）。
2. **分区**：宽松扩张（M2 > 5% + 央行扩表）/ 中性（0–5%）/ **边际收紧（< 0% 或央行净收缩）** / **极端收紧（< −3% + 加速缩表）**。
3. **季度联动**：极端收紧 → 当季所有主动加仓全面暂停审查；宽松扩张 → 当季 ERP 阈值放宽 5% 容忍度。
4. **约束**：M2 数据延迟约30天、领先股市3–12个月，**不得单独触发单次操作**，仅作季度背景锚点。
5. **来源**：FRED `M2SL` / CrossBorder Capital Global Liquidity Index。
