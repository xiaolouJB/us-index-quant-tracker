# 逻辑运算引擎：模块详细判定规则（每次巡检必读）

> 模块编号说明：A–K 为周度主巡检模块；Q、R 为 2026-06 新增周度模块；L/M/N 为季度模块（见 `references/quarterly.md`）。旧版季度模块编号 O/P 已退役，避免与历史报告混淆。

## 模块 A：估值与护城河计算（核心灯号触发器）
1. 计算盈利收益率 (E/P) = 1 / Forward P/E。
2. 计算股权风险溢价 (ERP) = E/P − US10Y。
3. 判定基准：
   - **黄金坑**：ERP 满足基准（NDX ≥ 2.0%，SPX ≥ 2.5%），且 P/S 与 CAPE（若适用）未触及极值红线。
   - **合理偏贵**：0% ≤ ERP < 基准要求，赚取盈利增长的钱。
   - **危险泡沫**：ERP < 0%，或 P/S 突破红线（NDX > 5.0x，SPX > 3.0x），或 CAPE 极度昂贵（SPX > 30）。

## 模块 B：宏观物理重力监测
1. 利率压制：若 US10Y > 4.35% 且持续攀升，判定为"宏观逆风"。
2. 资金链断裂预警：若 HY 信用利差急剧走阔，直接看空。

## 模块 C：微观情绪与博弈监测（含情绪面增强）
1. 结构集中度风险：若前十大成分股权重占比超自身极值（NDX > 50%，SPX > 30%），且等权重指数（NDXE 或 RSP）大幅跑输，判定为"抱团极致"，流动性脆弱。
2. 期权情绪：PCR < 0.6 为极度贪婪；PCR > 1.0 为恐慌（数据来源：`scripts/fetch_sentiment.py` 输出的 SPY/QQQ PCR）。
3. 波动率异动：若指数上涨且波动率（VXN 或 VIX）同步飙升，存在下杀风险。
4. **CNN 恐惧贪婪指数（增强项）**：
   - 0–25（极度恐惧）：逆向信号，绿灯/黄灯下的网格狙击置信度增强。
   - 25–45（恐惧）/ 45–55（中性）/ 55–75（贪婪）：常态区间，不修正操作。
   - 75–100（极度贪婪）：追高警示，任何灯号下禁止当日追涨买入，只允许回调后执行。
5. 情绪指标为辅助旁证，不单独触发灯号变更。

## 模块 D：长周期宏观极值否决
1. 若美国居民总资产中股票配置比例创历史新高（如 > 40%），宏观流动性增量枯竭。
2. 此时目标指数的"机动加仓"与"单日申购"额度必须强制打八折。标普定投动作视灯号调整。

## 模块 E：技术结构层（年线 + 多周期技术指标 + 分型结构）— 辅助参考
> 本模块为辅助层，不单独触发灯号变更，但影响操作细节与网格狙击时机判断。数据来源：`scripts/fetch_all.py`（均线）+ `scripts/fetch_technicals.py`（技术指标与分型）。

### E1. 年线结构（原有核心规则，保持不变）
1. **结构完好**：价格在年线（200日MA）上方 且 年线斜率向上 → 多头趋势延续，即便红灯也无即时崩盘信号。
2. **结构预警**：价格跌破年线但 5 日内快速收复 → 年线验证为真实支撑，提高后续跌破的警惕权重。
3. **结构破坏**：有效跌破年线（破位超 5 日未收复）→ 趋势性转弱，所有主动加仓冻结。
4. **操作联动**：
   - 🟡黄灯 + 结构完好 → 年线区间（价格离年线 < 5%）可启动网格狙击。
   - 🔴红灯 + 结构完好 → 记录年线位置作为未来观察窗口，当前不行动。
   - 🔴红灯 + 结构破坏 → 加速防御，机动资金全锁，定投减半或暂停。
   - 任何灯号 + 年线有效跌破未收复 → 所有加仓冻结。
5. **宽度辅助**：成分股站上 200 日线比例 < 40% → "市场内部走弱"，强化防御。

### E2. 中短期技术指标（增强项）
| 指标 | 判定规则 |
|------|---------|
| 50日均线 | 价格跌破 50DMA 且 50DMA 走平/下弯 → 中期动能转弱，网格狙击需等待企稳K线确认；50DMA 上穿 200DMA（金叉）为结构加分，下穿（死叉）为结构减分 |
| RSI(14) | > 70 超买：禁止追涨，网格卖出参考；< 30 超卖：若年线结构完好，网格狙击信号增强 |
| MACD(12,26,9) | 柱状图连续收缩/翻负 → 动能衰减预警；零轴下方金叉 → 反弹尝试信号（需其他模块共振确认） |
| 距 ATH 回撤 | 回撤 < 5%：高位区，狙击性价比低；5–10%：常规回调区；> 10%：进入技术性回调，结合灯号评估狙击窗口；> 20%：技术性熊市，触发牛市年龄模块重新锚定起点 |
| ATR(14) | 用于设定网格步长：单格间距 ≥ 1 × ATR%，防止震荡市频繁触发 |
| 周线趋势 | 价格站上 30 周均线 → 长波段健康；跌破且 2 周未收复 → 与年线破坏信号互相印证 |

### E3. 顶底分型结构（增强项 — swing 高低点判定）
1. **识别方法**：以 5 日窗口识别局部摆动高点（swing high）与低点（swing low），取最近 2 组高点 + 2 组低点。
2. **结构判定**：
   - **上升结构（HH + HL）**：高点抬高、低点抬高 → 趋势多头，回踩低点附近为网格参考位。
   - **下降结构（LH + LL）**：高点降低、低点降低 → 趋势空头预警；若同时跌破 50DMA，模块 E 整体判定降一档（完好→预警，预警→破坏倾向）。
   - **震荡结构（混合）**：区间市，按年线规则执行，网格步长用 ATR 加宽。
3. **顶分型/底分型提示**：最近一组 swing high 若伴随 RSI 顶背离（价格新高、RSI 未新高）→ 标注"顶部分型背离预警"；swing low 伴随 RSI 底背离 → 标注"底部分型背离信号"，作为狙击置信度加分项。

## 模块 F：牛市年龄（周期背景层）— 辅助参考注脚
1. **计算**：从最近一次熊市底部（跌幅 > 20% 后的反转点）起算；本轮起点锚定 **2022年10月12日**。
2. **历史基准**：战后美国牛市平均寿命约 4.6 年。
3. **分级解读**（配合估值灯号）：
   - 早期（0–2年）：赔率偏多方，支持积极操作。
   - 中期（2–4年）：估值红灯权重上升，严格执行灯号系统。
   - 成熟期（> 4年）：防御优先级最高；若 ERP 同时为负，视为复合极值风险。
4. **输出**：注明牛市年龄、历史均值消耗比例、赔率定性评级（偏多/中性/偏空）。
5. **约束**：不得单独作为减仓/止盈触发条件，必须与模块 A 联合判断。

## 模块 G：盈利修正方向（ERP 真实性校验层）— 辅助参考
> 校验 ERP 的"含金量"：是盈利上修而来，还是价格下跌被动改善？
1. **数据**：FactSet Earnings Insight 盈利修正比（过去4周上调/下调分析师数）；当季 EPS Beat Rate。
2. **判定**：
   - **含金量高**：修正比 > 1.0 且 Beat Rate > 70% → 可适当放宽操作阈值。
   - **中性**：修正比 0.8–1.0 → 正常执行灯号。
   - **存疑（ERP虚高）**：修正比 < 0.8 → 分母缩水中，估值判定上调一档风险。
3. **联动**：
   - 🟡黄灯 + ERP虚高 → 按实质性红灯处理，暂停加仓。
   - 🔴红灯 + 含金量高 → 维持红灯但降低防御烈度，保留小额脉冲窗口。
   - 🟢绿灯 + 含金量高 → 信号强化，可顶格执行。

## 模块 H：CNY/USD 汇率（QDII 实际收益层）— 专属辅助
1. **数据**：USD/CNY 即期价、近30日方向、近90日累计变动（`scripts/fetch_all.py` 输出）。
2. **判定**：
   - 人民币贬值（USD/CNY 上行）：QDII 汇兑增益，隐性利好，不改主灯号。
   - 人民币升值（下行）：若近90日升值超 3%，收益预期中扣除摩擦成本，主动加仓意愿降权。
   - 单月波动 > 2%：标注"汇率扰动期"，纳入风险提示。
3. **输出**：指令单附注汇率环境（顺风/中性/逆风）。

## 模块 I：宏观前瞻层（利率路径与衰退概率）— 辅助参考
1. **数据**：2s10s 利差（`scripts/fetch_fred.py`，FRED T10Y2Y）；CME FedWatch 年底前累计降息/加息隐含概率（人工核实）。
2. **收益率曲线**：
   - 正常化（> 0bp）：健康。
   - 平坦化（0 至 −50bp）：放缓信号，加风险注脚。
   - 深度倒挂（< −50bp）或倒挂后快速牛陡：宏观衰退预警激活，与模块 B 叠加强化红灯。
3. **Fed 路径**：
   - 预期年内降息 ≥ 2次（50bp+）：ERP 阈值可放宽 5–10% 容忍度。
   - 预期不变或加息：强化模块 B 宏观逆风。
4. **输出**：曲线形态 + Fed 路径 + 综合方向（顺风/中性/逆风）。

## 模块 J：暗池资金动向与 GEX（大机构情绪与流动性结构层）— 专属辅助
1. **数据**：`scripts/fetch_dark_pool.py`（SqueezeMetrics DIX/GEX）+ `scripts/fetch_options_walls.py`（QQQ/SPY 净 GEX 与 Gamma 翻转位）+ `scripts/fetch_fund_flow.py`（SPY/QQQ 主力大单净流入）。
2. **DIX 判定**：
   - **机构极度吸筹（DIX > 45.0%）**：强烈看涨/底背离信号。
   - **正常（40.0% < DIX ≤ 45.0%）**：常态。
   - **极度派发/无接盘（DIX ≤ 40.0%）**：看跌/破位预警。
3. **GEX 状态**：
   - **正 Gamma 压舱石（GEX > 0）**：做市商高抛低吸，抑制波动。
   - **负 Gamma 波动陷阱（GEX < 0）**：做市商追涨杀跌，连环跳水风险。
4. **ETF 主力大单资金流（增强项）**：
   - **主力净流入持续 > 0**：真金白银买盘，若叠加 DIX 吸筹，极大强化抄底信号。
   - **主力净流入持续 < 0**：筹码派发，若叠加高估值或负 Gamma，警惕加速下杀风险。
5. **操作联动（一票否决级）**：
   - **负 Gamma 熔断**：任何灯号 + GEX < 0 → 强制冻结所有主动加仓，仅保留周四定投，待 GEX > 0 解封。
   - **超级抄底共振**：🔴/🟡 + DIX > 45.0% 且 GEX 由负转正 且 主力大单买入 → 绝佳反转点，果断启动大额网格狙击。
   - **暗流溃败**：任何灯号 + DIX ≤ 40.0% 且 GEX < 0 → 立刻收缩战线，防守最优先。
6. **输出**：DIX 数值/机构行为判定 + GEX 数值/Gamma 状态 + 资金流状态 + 对操作的否决/冻结效果。

## 模块 K：巴菲特指标（市场整体估值长周期锚）— 辅助参考
> 「美股总市值 / 美国GDP」。与模块 D 共同构成双重长周期否决防线。
1. **数据**：`scripts/fetch_fred.py` 输出近似比率（Wilshire 5000 指数点位 / 名义GDP）；以 `currentmarketvaluation.com` 人工核实为准（注意：FRED `WILL5000IND` 已于2023年底停更，禁止再引用该代码）。
2. **分区**：
   - 低估区（< 100%）：战略性大底信号。
   - 合理区（100–150%）：正常执行。
   - 偏贵区（150–175%）：注脚预警，不单独触发变更。
   - **高危区（175–200%）**：长周期估值预警；叠加模块 D 时机动额度强制八折。
   - **极端泡沫区（> 200%）**：叠加任一红灯时机动额度五折，仅保留定投。
3. **联动**：
   - \> 175% + 模块D触发 → 双重否决：额度折上折（约 64%）。
   - \> 200% + 任一红灯 → 极端复合风险：机动全锁，待回落 175% 以下重启。
   - < 150% → 长周期托底：ERP 阈值放宽 5–10%，鼓励绿/黄灯积极执行。
4. **输出**：比率值、分区、与历史均值偏离、操作修正结论（无修正/八折/五折/托底放宽）。

## 模块 Q：相对强弱与领先指标层（2026-06 新增）— 辅助参考
> 通过跨指数/跨资产的相对强弱捕捉风格轮动与领先预警。数据来源：`scripts/fetch_all.py` 的"相对强弱与领先指标"段。不单独触发灯号，作为模块 C/E 的旁证。
1. **NDX/SPX 比价（20日趋势）**：上行 → 成长占优、风险偏好健康；下行 → 资金防御化，纳指操作降置信度。
2. **SOX 费城半导体（纳指领先指标）**：SOX 率先跌破自身 50DMA 而 NDX 尚未跌破 → "领先预警"，纳指网格狙击暂缓一档；SOX 强于 NDX → 科技内部健康。
3. **VUG/VTV 成长价值轮动（20日）**：比价下行 + NDX/SPX 比价下行双确认 → 风格切换成立，标普相对受益，纳指防御权重上调。
4. **DXY 美元指数**：> 105 强美元逆风（压制美股盈利与流动性）；< 100 顺风。
5. **铜金比（HG/GC，20日）**：持续下行 → 全球风险偏好收缩、衰退交易抬头，与模块 I 曲线信号互相印证。
6. **输出**：各项方向 + 领先指标净判定（顺风/中性/逆风），写入共用层快照。

## 模块 R：核心财报风向与事件窗口（2026-06 新增）— 强制注脚与微观对冲
> 将宏观日历与近期核心微观公司的财报结果结合，既管理未知风险，也量化已知业绩的影响。必须通过 WebSearch 核实。
1. **覆盖范围**：
   - **已知风险事件（未来1周）**：FOMC 议息会议、CPI、PCE、非农就业、核心巨头将要发布财报的日期。
   - **已落地财报（过去1周）**：前十大权重股（如七巨头）或核心半导体龙头（如美光、台积电等）最新发布的财报业绩与下季指引。
2. **判定（未来事件静默）**：
   - 未来 **24–48 小时内**有重大事件 → **事件窗口静默**：暂停网格狙击与机动加仓，事件落地后再执行原指令。
3. **判定（已落地财报定性对冲）**：
   - **强心针效应（超预期）**：若近期核心巨头财报极强（如营收暴增、指引超预期），当估值/宏观触发黄灯或红灯时，该财报可视为“短期多头对冲项”，在报告中明确指出其对恐慌抛售的缓冲作用，但**不改变原有防守灯号**。
   - **踩踏效应（暴雷）**：若核心巨头业绩不及预期或下修指引，且当前大盘处于高估值（ERP倒挂）或负 Gamma 区间，该财报视为“加速破位项”，强化看空指令。
4. **输出**：在共用层末尾输出【📅 本周风险窗口】表，记录未来事件及最近1周财报落地影响，并在“大白话深度解读”板块中强制结合核心财报影响进行宏微观综合分析。
